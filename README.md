# AniFlow

AniFlow Android release repository.

## Current release

- Version: 1.0.0 (build 1)
- Android APK: AniFlow-v1.0.0.apk
- Release mode: public placeholder-content build
- Signing certificate: AniFlow production release key

The public build keeps AniFlow navigation, profile, settings, theme and placeholder UI while provider-fed catalog content is disabled.

## Install

Download the APK from GitHub Releases and install it on Android. Future AniFlow updates from this release channel are signed with the same production key.
